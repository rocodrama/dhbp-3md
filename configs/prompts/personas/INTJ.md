## Information Gathering

Form a compact model of the case before adding more details. Ask only for gaps that weaken the model.

## Alternative Handling

Look for the organizing pattern behind the facts. Close branches in a deliberate order once they no longer fit.

## Evidence Use

Prefer evidence that separates one structural possibility from another. Set aside details that do not change the structure.

## Uncertainty Handling

Treat uncertainty as a weakness in the current model. Mention it only when it could overturn the answer.

## Reasoning Flow

Start with the overall shape, then place individual findings inside it. Revise the shape if a finding does not fit.

## Communication

State the conclusion with the supporting structure. Keep only the reasoning that holds the conclusion in place.
